oficial no es un adorno decorativo; es una síntesis geométrica de la soberanía de Florianópolis:

tipográfica dual que combina modernidad geométrica y legible con precisión técnica editorial. Text
┌────────────────────────┐ ┌────────────────────────┐ │ LEXEND │ │ INTER │ │ (Titulares / E-E-A-T)│
│ (Cuerpo / UI / Tablas│ │ Autoridad Contemporánea│ │ Claridad Óptica Máxima │
└────────────────────────┘ └────────────────────────┘ 3.1. Tipografía Display / Titulares: Lexend
Diseñada por Thomas Jockin bajo investigaciones cognitivas para facilitar la velocidad de lectura y
reducir la fatiga ocular. Uso Obligatorio: Titulares H1 a H3, logotipos apilados, cifras destacadas
de presupuestos públicos y llamadas a la acción en banners. Pesos Permitidos: 700 (Bold), 800
(Extra-Bold), 900 (Black). Variables CSS: --font-lexend. 3.2. Tipografía Sans-Serif / Interfaz y
Lectura: Inter Diseñada por Rasmus Andersson para interfaces de usuario y pantallas de ordenador de
alta resolución. Uso Obligatorio: Párrafos, campos de formulario, botones, navegación, modales y
textos descriptivos. Pesos Permitidos: 400 (Regular), 500 (Medium), 600 (Semi-Bold), 700 (Bold).
Variables CSS: --font-inter. 3.3. Tipografía Monospace / Evidencia Forense: ui-monospace,
SFMono-Regular, Menlo, Monaco, Consolas Uso Obligatorio: Hashes criptográficos SHA-256, números de
CNPJ/CPF anonimizados, identificadores UUID de denuncias y trazas de telemetría forense. 3.4. Escala
Tipográfica Modular Fluida (clamp) Para asegurar la lectura fluida en dispositivos móviles de gama
baja y pantallas de gran formato sin quiebres abruptos de diseño: CSS /_ Escala de Tipografía Fluida
Institucional _/ --font-display-hero: clamp(2.5rem, 1.8rem + 3.5vw, 5.5rem); /_ 40px -> 88px _/
--font-heading-h1: clamp(2.0rem, 1.5rem + 2.5vw, 3.75rem); /_ 32px -> 60px _/ --font-heading-h2:
clamp(1.5rem, 1.25rem + 1.2vw, 2.25rem); /_ 24px -> 36px _/ --font-heading-h3: clamp(1.25rem,
1.1rem + 0.75vw, 1.75rem); /_ 20px -> 28px _/ --font-body-regular: clamp(1.0rem, 0.95rem + 0.25vw,
1.125rem); /_ 16px -> 18px _/ --font-caption-meta: clamp(0.75rem, 0.7rem + 0.2vw, 0.875rem); /_ 12px

   Lucide Icons: Trazo Nominal (Stroke Width): 2px para elementos interactivos móviles (44px target)

   stroke-linejoin="round". Rejilla Base: Cuadrícula de 24 × 24px. Iconos Canónicos de la
   Organización: ShieldCheck: Transparencia activa, auditoría superada y seguridad de identidad.
   HandHeart / Heart: Solidaridad, amparo civil y donaciones. FileText: Partidas presupuestarias,
   actas y contratos públicos. AlertTriangle: Detección de anomalías en el gasto o riesgo en
   territorio. Lock: Mascaramento PII bajo la LGPD y confidencialidad de denunciantes. MapPin:
